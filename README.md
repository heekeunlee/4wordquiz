# 사자성어 퀴즈

초등학교 4–5학년을 위한 간단한 랜덤 퀴즈입니다. 뜻을 읽고 보기에서 사자성어를 고르면 됩니다. 한 판에 10문제가 나오며, 마지막에 점수와 틀린 문제를 보여 줍니다.

- 사진에서 정리한 사자성어 30개
- 정답 확인 후 다음 문제로 이동
- 단어장과 오답 다시 풀기
- GitHub Pages 자동 배포 (`main` 브랜치에 push)
- 앱 안에 문제를 넣은 오프라인 Android APK

정적 웹 파일은 `dist/`에 있습니다. Android 앱은 이 파일을 APK 안에서 불러오므로 설치 후 인터넷이 필요하지 않습니다.

## 갤럭시 A에 오프라인 설치하기

GitHub 저장소의 **Actions → Build offline Android app** 실행 결과에서 `saja-seongeo-apk`를 내려받아 압축을 풀면 `app-debug.apk`가 있습니다. APK를 컴퓨터에 저장한 뒤 USB 케이블로 갤럭시 A의 `Download` 폴더에 복사하고, 휴대폰의 **내 파일 → 다운로드**에서 열어 설치하세요. 설치 허용 안내가 나오면 `내 파일`에 한해 허용하면 됩니다.

이전 테스트 APK를 이미 설치했다면 새 앱을 설치하기 전에 이전 앱을 삭제해 주세요.
