# 사자성어 탐험대

초등학교 4–5학년이 사진에서 모은 사자성어 30개를 재미있고 편하게 익히는 모바일 우선 퀴즈입니다. 큰 글씨와 누르기 쉬운 보기, 응원 피드백, 단어장, 오답 다시 풀기, 기기 안에 저장되는 정답 기록을 담았습니다.

- 뜻 보고 맞히기 / 사자성어 보고 뜻 찾기
- 10·20·30문제 랜덤 라운드
- 점수와 정답률 기록, 틀린 문제 복습
- GitHub Pages 자동 배포 (`main` 브랜치에 push)
- 인터넷 연결 없이 작동하는 Android APK 빌드

정적 웹 파일은 `dist/`에 있습니다. 앱에서는 APK에 포함된 이 파일을 불러오므로 휴대폰에서 인터넷이나 Wi-Fi가 필요하지 않습니다.

## 갤럭시 A에 오프라인 설치하기

GitHub 저장소의 **Actions → Build offline Android app** 실행 결과에서 `saja-seongeo-apk`를 내려받아 압축을 풀면 `app-debug.apk`가 있습니다. APK를 컴퓨터에 저장한 뒤 USB 케이블로 갤럭시 A의 `Download` 폴더에 복사해 설치하세요. 설치할 때 `내 파일`의 앱 설치를 허용하라는 안내가 나오면 이번 설치에 한해 허용하면 됩니다. 설치 후에는 퀴즈와 정답 기록을 네트워크 없이 쓸 수 있습니다.
